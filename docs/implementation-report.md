# تقرير تنفيذ صنعة

التاريخ: 8 أكتوبر 2026. المنفذ: أجنت GPT 6.1 Sol للمشروع، دون أجنتات فرعية. المستودع مستقل على فرع `prototype`، محلي ولم يُرفع إلى خدمة عامة. ملاحظات مراجعة Astra وصلت عبر المنسق وأُصلحت باختبارات تراجع.

## ما نُفّذ

موقع عربي RTL متجاوب بألوان الحبر والنحاس والورق، يستخدم HTTP من Node ووحدات JavaScript أصلية دون حزم تشغيل. رحلة كاملة لمعلّم ومتعلّم مستقلين: إنشاء دليل، أدوات وخطوات ومتطلبات، تنفيذ خطوة واحدة خارج الشاشة، وصف الناتج، سؤال تعثر، توضيح بشرى، تجربة نسخة جديدة، إقراران لنسخة الدليل وطباعة وتصدير واستيراد.

الواجهة تقدم مثال طي منشفة مؤلفًا، رسم SVG حيًا للمتطلبات، أثر آخر تعديل، سجل نسخ، ومؤشرات محاولات وتعثر مُبلّغ عنها. التصدير لا يتضمن أسرار الدخول. الاستيراد يبني نسخًا محلية جديدة ويزيل الثقة في إقرارات الملف، ويبقى بانتظار مراجعة المعلّم.

## آلية وضمانات

- DAG حتى ١٢ خطوة، تحقق من المعرفات والدورات والمراجع والترتيب الطوبولوجي.
- بصمة سياقية للخطوة تشمل المحتوى ورقم النسخة وبصمات المتطلبات المتعدية؛ تعديل أصل يغير نسخة وصلاحية كل تابع ويحفظ تاريخها، بما يرفض إعادة الإقرار القديم حتى بعد إكمال الأصل الجديد.
- خادم يرفض إنجازًا قبل المتطلبات أو أثناء تعثر مفتوح أو من الدور الخطأ. توضيح المعلّم يحتاج تجربة جديدة من المتعلّم. اكتمال الدليل يحتاج إقرارين بالدورين لنسخة واحدة.
- تهيئة تعرض رمز المعلّم ودعوة أحادية فقط؛ المتعلّم يختار سره مستقلًا من ١٢ حرفًا على الأقل. لا كشف أو استرجاع سره من حساب المعلّم ولا إعادة دعوة بعد الانضمام. رموز منتهية، وتخزين بصمات فقط.
- كل mutation معاملة متسلسلة على نسخة مرشحة، حفظها قبل نشرها. فشل الكتابة لا يغير الحالة العامة، ولا يسمم طابور الحفظ التالي.
- ربط 127.0.0.1، تحقق مضيف وأصل، جسم حتى ٦٤ كيلوبايت، CSP، ترميز نصوص الواجهة والطباعة، وعدم تسجيل الأسرار أو المحتوى في السجلات.

## الاختبارات الفعلية

المراحل الحمراء محفوظة في `docs/evidence/`: قبل المحرك، قبل HTTP، قبل انضمام المتعلّم المستقل، ثم تراجعات النسخ والحفظ. الاختبارات الأولى شاهدت غياب التنفيذ. تراجعا Astra شاهدَا خطأ فعليًا: قبول إقرار تابع قديم، ونشر تعديل رغم فشل حفظه.

النسخة الحالية: **١٨ اختبارًا ناجحًا، صفر فشل، صفر تخطي** عبر `node --test`. الاختبارات الأساسية تشمل ٢٥٦ مقارنة مع مرجع وصول مستقل (٦٤ DAG × ٤ تعديلات)، كما تشمل HTTP حقيقيًا على loopback، إعادة التحميل من الملف، طلبات مزورة وأصول خاطئة وجسمًا زائدًا، طباعة XSS مرمزة، وانضمام الدعوة مرة واحدة.

اختبار الحفظ حوّل مسار ملف الحالة في مجلد مؤقت إلى مجلد فعلي ليجبر الكتابة على الفشل؛ تحقق بقاء الحالة السابقة، ثم أعاد الملف وتحقق نجاح كتابة لاحقة وحفظها على القرص. لم يستخدم ادعاء نجاح من محاكاة store.

Gemini: adapter جاهز configurable، الافتراضي `gemini-3.5-flash-lite`، endpoint generateContent خادمي، timeout ١٢ ثانية، مخطط JSON وإعادة تحقق. consent مطلوب ومراجعة المعلّم قبل نشر المسودة. لا API key مقدم ولا اتصال حي؛ **HTTP محاكى فقط** يشمل نجاح مسودة، schema غير صالح، timeout، وعدم نشر تلقائي.

في البيئة المقيدة منع sandbox اتصالات loopback (`EACCES`)، فجرى تشغيل اختبارات HTTP ضمن التفويض المرتفع المحلي؛ لم تُفسّر مشكلة البيئة كنتيجة نجاح. نواتج آخر تحقق محفوظة في `docs/evidence/verify.txt`.

## البناء والعرض

`npm start`، `npm test`، `npm run build`، `npm run verify` موثقة. build يتحقق من صياغة كل وحدة إنتاج ووجود الأصول، وينسخ runtime مستقلًا إلى `dist/` مع manifest بصمات دون بيانات المساحة. README يتضمن سبعة Mermaid وثلاثة SVG أصلية مستقلة قابلة للعرض، إضافة إلى SVG DAG حي في الموقع.

الفحص التفاعلي للمتصفح ولقطات سطح المكتب والهاتف يجريها المنسق. لا ينسب هذا التقرير نتيجة بصرية لم تُرسل بعد، ولا تولد الصور التوضيحية دليل تحقق للواجهة. ملفات Word والعروض خارج نطاق هذا المستودع ويكملها المنسق.

## حدود صريحة

استقلال الرمزين لا يثبت وجود شخصين مختلفين: أول مستعمل للدعوة ينضم، وقد يكون منشئ المساحة نفسه، وحامل رمز آخر يستطيع استعماله. لا تحقق هوية بشرية أو تنفيذ مادي أو سلامة أو جودة. عبارة «جرّبه عضو آخر» تعني إفادتي الدورين فقط ضمن هذه الحدود الظاهرة في الواجهة.

مساحة محلية واحدة لمعلّم ومتعلّم، لا خدمة متعددة الأسر أو نشر إنتاجي أو استرجاع حسابات. لا كتابة متزامنة من خادمين لملف الحالة نفسه، ولا مطالبة بضمان durability أمام قطع الكهرباء؛ الحفظ يستخدم استبدال ملف ولا fsync. البيانات الذاتية ليست نتائج اجتماعية أو دراسات، ولم يوجد مستخدمون فعليون أو أثر أسري مقاس.

المنافسون وGemini موثقون بصفحاتهم الرسمية في `sources.md`. لم ندع أن حفظ الوصفات أو التعاون العائلي ابتكار، ولا أن غياب ميزة من صفحة عامة يثبت غيابها من المنتج.

## سجل التغييرات والمراجعة

1. اختبارات قبول أولًا ثم المحرك، وإعلان core-ready بعد ٩ اختبارات ناجحة.
2. خادم HTTP وواجهة عربية كاملة، ومهايئ Gemini غير الناشر.
3. استبدال تسليم رمز المتعلّم للمعلّم بدعوة أحادية واختيار سر مستقل، مع اختبارات RED→GREEN.
4. إصلاح معاملتي الحفظ والنسخ السياقية استجابة لمراجعة Astra، مع اختبار فشل فعلي ثم تحقق نجاح الإصلاح.
5. توثيق عربي وبناء مستقل وأدلة تشغيل. تحقق `npm run verify` في 8 أكتوبر 2026: ١٨/١٨ اختبارًا و١٤ ملف إنتاج، صفر حزم تشغيل. التنفيذ الأول مثبت في commit `6b709b423630c81a651f92cb0c5fe71fabcb426a` على فرع `prototype`؛ تحديثات المراجعة موثقة في commits لاحقة. شجرة العمل نظيفة عند تثبيت التنفيذ، ولم تُرفع إلى remote.
6. مراجعة Astra الأخيرة أثبتت قبول إقرارات جولة قديمة عند إنشاء دليل بنفس المحتوى. أضيف `instanceId` عشوائي جديد داخل `versionGuide` لكل إنشاء أو استيراد، يدخل بصمات جميع الخطوات وdigest الدليل. لا يعتمد على الهوية داخل الملف المستورد. أثبت اختبارا RED قبول الإقرار القديم قبل الإصلاح (`docs/evidence/instance-red.txt`)، ثم GREEN رفض hashes القديمة للخطوات وإقرارات الدورين القديمة حتى بعد إكمال الجولة الجديدة. لا تصبح `tested=true` إلا بإقرارين جديدين للجولة الحالية. التحقق النهائي كامل، كما يسجله `docs/evidence/verify.txt`.
