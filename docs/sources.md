# مصادر وحدود المقارنة

راجعت الصفحات الرسمية التالية عبر الويب في 8 أكتوبر 2026. قراءة صفحة المنتج لا تعادل تثبيت المنتج أو اختبار كل خصائصه. لم نستنتج غياب ميزة لأن الصفحة لم تذكرها، ولا ندعي جدة عالمية أو أهلية براءة.

- [Morsel](https://getmorsel.com/): توثيق وصفات عائلية ومجموعات ومذكرات صوتية وأسئلة وتعليقات على الناتج. بديل قريب؛ حفظ وصفة والسؤال عن تجربتها ليسا فرقًا جديدًا لصنعة.
- [Gigi Collaborative Cookbooks](https://www.gigicc.com/): كتب وصفات خاصة ومشاركة الأسرة وتحرير مشترك وملاحظات. الخصوصية وتعدد المشاركين والتحرير ليست ادعاء تميز لصنعة.
- [Scribe](https://scribe.com/): التقاط طريقة تنفيذ العمل وتحويلها إلى توثيق وإرشادات. فرق النطاق المقصود هو مهارة مادية وتجربة معلّم/متعلّم مع اعتماديات ونسخ، لا تصوير شاشة الكمبيوتر.
- [نماذج Gemini](https://ai.google.dev/gemini-api/docs/models): تذكر القائمة `gemini-3.5-flash-lite`. الاسم قابل للتغيير بمتغير بيئة؛ لا مفتاح مقدم أو اتصال حي محقق.
- [generateContent API](https://ai.google.dev/api/generate-content): مرجع الواجهة المستخدمة للمحتوى مع مخطط JSON. المهايئ خادمي، والموافقة والمراجعة بشريتان.

حد الفرق القابل للعرض: إقرار تجربة لنسخة سياقية من خطوة، منع إنجاز تابع قبل متطلبه، سؤال واضح مرتبط بخطوة، وتعديل يعيد الفرع المتأثر مع حفظ الفرع المستقل. هذا تنفيذ محلي قابل للاختبار. سهولة هذه الدورة وفائدتها الأسرية تحتاجان دراسة استخدام فعلية.
